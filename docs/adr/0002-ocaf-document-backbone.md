# ADR 0002: OCAF is the document backbone

* Status: Accepted
* Date: 2026-09-19

## Context

The platform needs a durable decision for this concern before feature expansion.

## Decision

Use OCAF labels, attributes, transactions, persistence, driver execution and TNaming from the first parametric-document implementation.

## Consequences

Feature parameters and dependency state are not duplicated in a parallel document model. M1 starts with a focused save/reload/recompute spike.
