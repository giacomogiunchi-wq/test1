# ADR 0010: Vertical slices and deferred DEM

* Status: Accepted
* Date: 2026-09-19

## Context

The platform needs a durable decision for this concern before feature expansion.

## Decision

Deliver milestones sequentially: skeleton, parametric CAD, STEP, FEM, multibody, then CFD. LAMMPS GRANULAR remains optional and post-MVP.

## Consequences

The project validates architecture with narrow end-to-end slices and does not accumulate broad, untested placeholders as implementations.
